Hosten oder eigener Server.

Hosten geht direkt im Spielmenü. Für den Homeserver gibt es den Server als eigenes Programm.

Anti-Cheat
Der Server entscheidet alles. Speedhacks bringen nichts, getarnte Panzer und alles im Nebel werden gar nicht erst verschickt.
Chat, Kick und Bann
Spielerliste mit Ping, Chat im Spiel und Banns, die auch nach dem Wiederkommen gelten.
Kleine Pakete
UDP mit typisch 30 bis 100 Byte pro Paket. Wer dazukommt, wartet auf die nächste Runde, statt sie neu zu starten.
# Server mit 2 Bots starten
./panzer-server --port 5555 --bots 2

# Mit Admin-Passwort, im Spiel dann /login <Passwort>
./panzer-server --bots 2 --admin-pass geheim

Der Server braucht UDP-Port 5555. Deine Freunde wählen im Spiel Beitreten und geben die IP ein.

Herunterladen

Für Windows, macOS und Linux. Der Launcher installiert das Spiel beim ersten Start und hält es danach aktuell. Kostenlos, ohne Konto.

Windows

Installer ohne Admin-Rechte. Er ist nicht signiert, SmartScreen warnt deshalb: erst „Weitere Informationen“, dann „Trotzdem ausführen“.

Installer

macOS

Für Intel und Apple Silicon, ab macOS 11. Nicht von Apple signiert: Nach dem ersten Startversuch unter Systemeinstellungen, Datenschutz & Sicherheit auf „Dennoch öffnen“ klicken.

Disk-Image

Linux

Für Debian 12, Ubuntu 22.04 oder neuer. Die AppImage vor dem Start ausführbar machen, das Paket mit sudo apt install ./panzer-launcher_amd64.deb installieren.
